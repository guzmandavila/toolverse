# Toolverse

Portal de herramientas digitales de Ronald Guzmán Dávila. Sitio estático para GitHub Pages, sin dependencias de compilación.

## Herramientas

- **Plantilla de noticia 16:9:** cambia la foto, edita los textos y exporta a PNG.
- **Editor de placa:** editor de placas gráficas en `guzmandavila.github.io/Editor-de-placa/`.

## Publicación

El workflow de GitHub Actions publica el contenido de `main` a GitHub Pages en cada push. URL del proyecto: `https://guzmandavila.github.io/toolverse/`.
